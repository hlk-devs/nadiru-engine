# Code of Conduct

## Short Version

Be respectful. Be constructive. Help each other build something good.

## Longer Version

This project welcomes contributions from everyone. We're building an open source tool, not a community drama platform.

**Expected behavior:**
- Constructive feedback on code and ideas
- Respectful disagreement
- Helping newcomers get oriented
- Focusing on what's best for the project

**Not tolerated:**
- Personal attacks or harassment
- Trolling or deliberately inflammatory comments
- Publishing others' private information
- Any behavior that makes people not want to contribute

## Enforcement

If someone is being a problem, open an issue and the maintainers will handle it.

## Scope

This applies to all project spaces — issues, pull requests, discussions, and any related communication channels.
